## tldraw — how this project uses it (low-fi only)

| Concept | In this project |
|---|---|
| Low-fi | `.tldr` files under `design/low-fi/<feature-slug>.tldr`, or a shared board link the developer provides |
| Review / approvals | open in tldraw; approval marker with the file path (and commit) or board link |
| Hi-fi / UI Kit | not supported: use the hi-fi tool configured for the project |

## Operation → tool

| Operation | How |
|---|---|
| `design.read` / `design.create` / `design.update` | edit the `.tldr` JSON with the harness's file tools, or ask the developer to edit a shared board |
| `design.link` / `design.version` | repo path + commit, or the board link + date |
| `design.export` / `design.components` | unavailable |
